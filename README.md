# Калькулятор синергии продаж

Калькулятор для созвонов с владельцами брендов в Instagram. Показывает примерный прирост выручки, когда к продажам через Директ подключаются инструменты автоматизации.

Стек: Next.js (статичная сборка), TypeScript, Tailwind CSS, GitHub Pages.

## Как считается

Вводятся примерные значения: лиды в Директ в день, средний чек и текущая конверсия (по умолчанию 20, 5 000 ₽ и 10%). Месяц считается за 30 дней.

- **Слово в комментариях + Автоответ** удваивает лиды.
- **Сайт с онлайн-оплатой** умножает конверсию на 1,35.
- **Бот-реаниматор / Дожимы** умножает конверсию на 1,15.

Текущая выручка = лиды × 30 × текущая конверсия × чек. Новая выручка считается так же, но с лидами и конверсией после инструментов. Прирост = новая − текущая. Результат примерный.

Формулы лежат в `lib/calculator.ts`, тексты резюме для каждого сочетания инструментов в `lib/summaries.ts`.

## Деплой на GitHub Pages

1. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
2. Сайт обновляется сам после каждого пуша в `main` и открывается по адресу `https://<ваш-логин>.github.io/profit-audit/`.

## Локальная разработка

```bash
npm install
npm run dev
```
